# 🌍 Geoestadística aplicada al análisis espacial

Este repositorio contiene una colección de scripts, reportes técnicos y recursos didácticos enfocados en **análisis geoestadísticos** aplicados a datos espaciales en contextos ambientales. Los materiales están organizados por temas y cubren desde análisis descriptivos básicos hasta modelos espaciales más avanzados como kriging y regresión espacial.

## 📂 Estructura del repositorio

| Carpeta / Archivo | Descripción |
|-------------------|-------------|
| `scripts/`        | Scripts en R utilizados para los análisis estadísticos y espaciales. |
| `data/`           | Archivos de entrada y ejemplos de datos espaciales. |
| `docs/`           | 📄 Reportes técnicos en PDF que explican los análisis paso a paso. |
| `README.md`       | Este archivo con la descripción general del proyecto. |

## 📄 Reportes técnicos disponibles en `/docs`

A continuación se listan los reportes incluidos en la carpeta `docs`, ordenados temáticamente:

| Archivo PDF | Descripción |
|-------------|-------------|
| `1_Analisis_descriptivo_unidimensional.pdf` | Análisis exploratorio de una sola variable espacial. |
| `2_Analisis_descriptivo_bidimensional.pdf` | Análisis conjunto de dos variables espaciales. |
| `3_Distribuciones_estadisticas.pdf` | Evaluación de distribuciones estadísticas aplicadas a datos ambientales. |
| `4_Autocorrelacion_espacial.pdf` | Evaluación de la dependencia espacial entre observaciones. |
| `5_Simulacion bootstrap no param.pdf` | Simulación de incertidumbre mediante métodos bootstrap. |
| `6_Distribucion_discreta.pdf` | Análisis de datos discretos en entornos espaciales. |
| `8_Generacion de puntos muestreo.pdf` | Métodos para generar puntos de muestreo espacial. |
| `9_Semivariogramas.pdf` | Construcción e interpretación de semivariogramas. |
| `10_Interpolacion_krigging.pdf` | Interpolación espacial mediante el método de kriging. |
| `11_ANOVA_ANCOVA.pdf` | Aplicación de ANOVA y ANCOVA en datos espaciales. |
| `12_Regresion_Espacial.pdf` | Modelado de relaciones espaciales mediante regresión. |
| `13_Almacenes_de_carbono.pdf` | Aplicación geoestadística al análisis espacial de carbono. |

---

Todos los análisis priorizan la representación espacial, el modelado estadístico y la interpretación reproducible en contextos ambientales. Este repositorio puede servir como base formativa o técnica para proyectos que integren herramientas de geoestadística y ciencia de datos geoespaciales.
